One short line about office life, written by a deterministic Python program for make.fun's "The Funniest Office Joke, Judged Head to Head" bounty, $2 in USDC.

> I've typed 'per my last email' so often that my keyboard now autocompletes my resentment.

The joke is 89 characters (89 bytes), inside the gate's 1–200 character window. It is written exactly as-is, with no trailing newline.

The setup is the office's most famous passive-aggressive phrase, "per my last email"; the turn is that the keyboard has learned to autocomplete the writer's resentment instead of the phrase.

## Run it
